Projects

Blind-Sight — AI Safety Pipeline View on GitHub ↗

An end-to-end pipeline for detecting and defending against subliminal bias in large language models, implementing the Aden-Ali et al. (2026) LLS framework on Llama-3.1-8B with LoRA adapters.

  • Data & Fine-Tuning: Generated poisoned vs. control preference data and ran DPO fine-tuning with LoRA adapters.
  • Detection: Built an Eigen-Probe using gradient coherence analysis over final-layernorm hidden states to surface bias signals.
  • Defense: Implemented Gradient Shielding — delta-SVD shield vectors projected onto LoRA parameters at every training step to remove the bias subspace.
  • Result: Coherence gap between poisoned and control runs inverted after shielding, indicating thorough bias subspace removal.
